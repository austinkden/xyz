# Agent Settings

Configure Antigravity behavior by toggling checkboxes (`[x]` = enabled, `[ ]` = disabled).
Delete any line to remove a setting completely.

- [ ] **autoPush** — Push commits to GitHub and submodules automatically
- [x] **autoCommit** — Create git commits automatically after making changes
- [x] **includeAntigravityCommitSuffix** — Append "Pushed automatically by Antigravity" to commit messages
- [x] **autoSyncSubmodules** — Keep universal.js and shared assets synced across about, control, schedule, utility
- [x] **bumpCachebusters** — Increment ?v=X query strings in HTML when scripts/styles change
- [x] **strictSyntaxValidation** — Verify JS/CSS brackets and syntax balance before committing
- [x] **allowBrowserTesting** — Allow launching browser subagents to test and verify UI
- [x] **askClarificationOnAmbiguity** — Ask clarifying questions instead of guessing if requirements are vague - even if it stops a flow
- [ ] **createChangeArtifacts** — Create markdown artifact files in IDE brain for major changes
